# Design context
## North Star
A personal French-language portfolio for Aicha Ouabi Idar: management systems that create value. Marketing register. No invented clients, testimonials, certifications or portraits.
## Visual direction
Airy asymmetric typography and a circular management-system diagram, grounded in ISOLEAN. Manrope headings, Inter body. Quiet surfaces and process lines; no generic corporate photos.
## Tokens
Runtime owner: src/styles.css. Deep teal #1a535c; turquoise #4ecdc4; off-white #f7fff7; coral #ff6b6b; yellow #ffe66d. Dark mode reverses surface and foreground using the same palette. Main width 1200px, section spacing 100px, small radii.
## Behavior
Shared section heading and action styles. French UI; English only for Co-Founder of VA CONSULTING. Sticky anchor navigation, native disclosures, phase buttons, explicit mailto form, configurable LinkedIn. Keyboard focus, reduced motion, visible scrollbars, mobile menu, stored theme.
## Content evidence
User supplied portfolio brief, with React/Vite/Tailwind overriding its stack. PDF is editorial evidence only. Profile image slot: src/assets/profile.png; ProcessArt is an interactive expertise radar with five buttons and native modal details.
